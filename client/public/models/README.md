# Character models

- `kenney/` : Kenney "Animated Characters 2" (CC0, https://kenney.nl). FBX model, idle/run animations and two team skins.
  Original pack kept in `assets-src/kenney-animated-characters-2/`.
- `character.glb` (optional): drop a rigged, animated glb here to override the Kenney character.

If neither loads, the game falls back to the built-in blocky soldier.
