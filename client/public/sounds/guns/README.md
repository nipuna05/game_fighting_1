# Real gun recordings (optional)

The game synthesises a different sound for every weapon. If you drop a real recording here it is used instead, with a little
random pitch variation per shot, the same distance filtering, stereo panning and reverb.

File names (ogg): `usp.ogg deagle.ogg glock.ogg mp5.ogg p90.ogg spas12.ogg striker.ogg ak47.ogg m4a1.ogg l118a.ogg m60e4.ogg barrett.ogg`

Use one short single shot per file (0.3 to 2 s). Only add recordings you are allowed to ship (for example CC0 packs from
freesound.org or Kenney / Sonniss GDC game-audio bundles) and note the licence in the in-game credits.
