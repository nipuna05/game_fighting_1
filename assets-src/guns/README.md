# Gun models go here (one GLB per weapon)

File names must match the weapon ids used by the game:

    usp.glb       deagle.glb    glock.glb                  (sidearms)
    mp5.glb       p90.glb                                  (SMG)
    spas12.glb    striker.glb                              (shotguns)
    ak47.glb      m4a1.glb                                 (rifles)
    l118a.glb     barrett.glb                              (snipers)
    m60e4.glb                                              (LMG)

You do not need all twelve. Any weapon without a file keeps its built-in low-poly model.

Also add a CREDITS.txt in this folder: for every model, one line with
"Model name - author - licence - link". CC-BY models require this credit.
Prefer models under about 30,000 faces so the game loads quickly in the browser.
