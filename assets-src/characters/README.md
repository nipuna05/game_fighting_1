# Other characters (e.g. from Poly Pizza, Sketchfab, Kenney)

Put each character in its own file here, named after what it is, for example:

    soldier-polypizza.glb
    police.glb

Notes:
- GLB is best. The model must be RIGGED (have a skeleton) and come with ANIMATIONS (at least idle and run)
  to move properly in the game. A static (unrigged) model can only slide around without moving its legs.
- Add one line per model to CREDITS.txt in this folder: "Model name - author - licence - link".
  CC-BY models require that credit. CC0 models do not, but it is polite.
